# 화면 설계안 (초안)

대상 사용자: IT 지식이 없는 유지보수 업체 직원.
목표: 설명서 없이 **언어 선택 → 점검 시작 → 보고서 받기**를 끝낸다.

이 문서는 승인용 초안이다. 문구는 `crates/i18n/locales/*.json`으로 옮겨 관리한다.

## 1. 화면 흐름

```
[첫 실행] 언어 선택 → 안내·동의
     │
     ▼
   [홈] ──► [점검 정보 입력] ──► [진행] ──► [결과] ──► 보고서 열기 / 인쇄
     │                                         │
     ├──► [지난 내역] ◄────────────────────────┘
     ├──► [설정] (기본 / 고객사 / 고급)
     ├──► [수집해 둔 자료 분석] (고급)
     └──► [도움말]
```

모든 화면 오른쪽 위에 **[한국어 | English]** 전환 버튼이 있다.

## 2. 화면별 구성

### 2.1 첫 실행

```
┌──────────────────────────────────────────────┐
│            언어를 선택하세요                 │
│            Choose your language              │
│                                              │
│        [  한국어  ]      [  English  ]       │
└──────────────────────────────────────────────┘
        ▼
┌──────────────────────────────────────────────┐
│ 이 프로그램은                                │
│  • PC에 연결된 장치, 열어 본 파일, 지운 파일 │
│    등의 기록을 모아 보고서로 만듭니다.       │
│  • 1차 점검용이며 법정 증거용이 아닙니다.    │
│  • 점검할 권한이 있는 PC에서만 사용하세요.   │
│                                              │
│ [✓] 위 내용을 확인했습니다                   │
│                          [ 시작하기 ]        │
└──────────────────────────────────────────────┘
```

### 2.2 홈

```
┌──────────────────────────────────── [한국어|English] ┐
│  Securidge Trace                                     │
│                                                      │
│        ┌────────────────────────────────┐            │
│        │                                │            │
│        │      이 PC 점검 시작           │            │
│        │                                │            │
│        └────────────────────────────────┘            │
│                                                      │
│   [ 지난 내역 ]   [ 설정 ]   [ 도움말 ]              │
│                                                      │
│   고급: 수집해 둔 자료 분석                          │
└──────────────────────────────────────────────────────┘
```

### 2.3 점검 정보 입력

```
  고객사        [ 고객사A            ▼ ]  [새 고객사]
  PC 이름       [ DESKTOP-ABC123       ]  (자동으로 채워짐)
  점검자        [ 홍길동               ]
  점검 기간     (•) 최근 30일  ( ) 90일  ( ) 1년  ( ) 전체  ( ) 직접 지정
  보고서 언어   (•) 한국어  ( ) English

  [✓] 이 PC를 점검할 권한이 있습니다

                         [ 뒤로 ]  [ 점검 시작 ]
```

- 필수 입력은 "권한 확인" 하나뿐. 나머지는 기본값이 채워져 있다.
- 관리자 권한이 없으면 여기서 안내한다:
  "이 PC의 모든 기록을 보려면 관리자 권한이 필요합니다. [관리자 권한으로 다시 실행] / [지금 계정의 기록만 점검]"

### 2.4 진행

```
  ① 자료 모으는 중 ........ 완료
  ② 기록 읽는 중 .......... 진행 중 (연결됐던 장치 기록을 읽고 있습니다)
  ③ 보고서 만드는 중 ......

  ████████████░░░░░░░░  62%

                                   [ 취소 ]
```

### 2.5 결과

```
  ●  확인 필요                       점검: 2026.11.21.(토), 18:01:02

  주요 내용
   1. 11월 3일(화) 밤 10시 12분, 처음 연결된 USB 저장장치에서 문서 12건이 열렸습니다.
   2. 같은 날 밤 10시 30분, PC의 파일 8건이 휴지통으로 옮겨졌습니다.

  다음에 할 일
   • 이 장치가 회사 장치인지 확인하세요.
   • '확인 필요' 항목은 보안 전문가의 검토를 받으세요.

  [ 보고서 열기 ]  [ 인쇄 ]  [ 저장 폴더 열기 ]  [ 다른 언어로 다시 만들기 ]

  연결됐던 장치
   SanDisk Ultra 64GB   처음 11.03.  마지막 11.03.   [ 회사 장치로 등록 ]
```

등급 표시: **특이사항 미발견(분석 범위 내)** / **주의** / **확인 필요** / **판단 불가(자료 부족)**

### 2.6 지난 내역

```
  검색 [ 고객사 ▼ ] [ 기간 ▼ ] [ 등급 ▼ ]

  점검 일시                     고객사    PC          점검자   결과
  2026.11.21.(토), 18:01:02     고객사A   PC-01       홍길동   ● 확인 필요
  2026.11.20.(금), 10:15:40     고객사B   DESKTOP-9   홍길동   ● 미발견

  선택한 내역:  [ 보고서 열기 ] [ 다른 언어로 다시 만들기 ] [ 폴더 열기 ] [ 내보내기 ] [ 삭제 ]
```

- 열 때 저장된 해시와 비교해 파일이 바뀌었으면 경고한다.
- 1년이 지난 내역에는 "보관 기간 확인" 표시를 붙인다.

### 2.7 설정

| 탭 | 항목 |
|---|---|
| 기본 | 화면 언어, 보고서 기본 언어, 표시 시간대, 업체명, 기본 점검자, 로고, 저장 위치, 기본 점검 기간 |
| 고객사 | 고객사 이름, 업무 시간·근무 요일, 회사 장치 목록(추가·삭제·메모) |
| 고급 | 규칙별 사용 여부·기준값, 주소 분류표, 개인정보 옵션, 수집본 보관 ("잘 모르면 그대로 두세요") |

공통 버튼: [기본값으로 되돌리기] [설정 내보내기] [설정 가져오기]

## 3. 문구 원칙

- 전문 용어를 쓰지 않는다. (레지스트리 → "Windows 설정 기록", 아티팩트 → "기록", 해시 → "변조 확인 값")
- 오류는 "무슨 일이 생겼는지 + 무엇을 하면 되는지"로 쓴다.
  - 나쁜 예: "ERROR_ACCESS_DENIED (5)"
  - 좋은 예: "이 PC의 기록을 읽을 권한이 없습니다. 프로그램을 닫고, 아이콘을 오른쪽 클릭해 '관리자 권한으로 실행'을 선택하세요."
- 사람을 지목하지 않는다. "김OO이 반출" ❌ → "kim 계정에서 … 기록이 있습니다" ⭕

## 4. 확인이 필요한 것

- 화면 방식(egui / Slint / Tauri)은 Phase 0 보고서의 D1에서 결정한다.
- 위 구성도는 방식과 무관한 배치 초안이다. 색·글꼴 등 디자인은 방식이 정해진 뒤에 한다.
