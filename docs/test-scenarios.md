# 시험 데이터 만들기 절차서 (초안)

이 도구가 내놓는 결과가 **맞는지** 확인하려면, 정답을 미리 아는 데이터가 필요하다.
가상 머신에서 아래 행동을 직접 하고 **한 시각을 초 단위로 적어 두면** 그것이 정답지가 된다.

> 이 절차는 KM이 직접 수행해야 한다. 개발 환경(Linux)에서는 만들 수 없다.

## 0. 준비물

- 가상 머신 프로그램 (VMware, VirtualBox, Hyper-V 중 아무거나)
- Windows 10 가상 머신 1대, Windows 11 가상 머신 1대 (평가판 가능)
- **시험 전용 USB 메모리 2개** (A: "회사 장치" 역할, B: "처음 보는 장치" 역할). 실제 자료가 없는 것
- 스마트폰 1대 (USB 케이블 연결용)
- 시계: 가상 머신 화면 오른쪽 아래 시계를 기준으로 삼는다. **시작 전에 인터넷 시간과 동기화**

## 1. 공통 규칙

- 가상 머신을 새로 설치한 직후 **스냅샷(S0)**을 찍는다. 시나리오마다 S0으로 되돌린 뒤 시작한다.
- 실제 개인정보(이름, 메일, 실제 문서)를 쓰지 않는다. 계정 이름은 `tester1`, `tester2`, 문서는 아래 "시험 문서"만 쓴다.
- 각 행동 사이에 **최소 2분** 간격을 둔다 (기록이 서로 구분되도록).
- 행동할 때마다 기록표(4장)에 **시각(시:분:초)과 한 일**을 적는다.
- 시나리오가 끝나면 가상 머신을 **정상 종료**하고, 가상 디스크 파일을 그대로 보관한다.

### 시험 문서 (미리 만들어 둘 것)

| 파일 | 위치 |
|---|---|
| `견적서_시험.xlsx`, `계약서_시험.docx`, `메모_시험.txt` | `C:\Users\tester1\Documents\시험문서\` |
| `usb문서_시험.docx`, `usb사진_시험.jpg` | USB B의 `\자료\` |

## 2. 시나리오

### S1. USB 저장장치 연결 → 열람 → 삭제 (핵심)

1. `tester1`로 로그인
2. USB B를 꽂는다 → **시각 기록**, 드라이브 문자 기록(예: E:)
3. 명령 프롬프트에서 `vol E:` 실행 → **볼륨 일련 번호 기록** (예: `1A2B-3C4D`)
4. 장치 관리자에서 USB B의 제조사·모델 기록
5. USB의 `usb문서_시험.docx`를 더블클릭해 연다 → 시각 기록 → 닫는다
6. PC의 `견적서_시험.xlsx`를 **USB로 드래그해서 복사** (열지 않는다) → 시각 기록
7. PC의 `계약서_시험.docx`를 연 뒤 "다른 이름으로 저장"으로 USB에 저장 → 시각 기록
8. PC의 `견적서_시험.xlsx`를 휴지통으로 삭제 → 시각 기록
9. "하드웨어 안전하게 제거"로 USB를 뺀다 → 시각 기록
10. 정상 종료

*확인하려는 것:* 연결·제거 시각, 볼륨 일련 번호가 바로 가기에 남는지, **6번(열지 않고 복사)이 기록에 남지 않는다는 것**

### S2. 같은 USB를 다시 연결

S1 직후 상태에서(되돌리지 않고) 다음 날 USB B를 다시 꽂았다 뺀다 → 시각 기록.
*확인하려는 것:* 최초 연결 시각과 최종 연결 시각이 구분되는가

### S3. 스마트폰 연결

1. 스마트폰을 USB로 연결하고 "파일 전송" 선택 → 시각 기록, 기종 기록
2. 탐색기로 스마트폰 저장소를 열어 본다 → 시각 기록
3. PC의 `메모_시험.txt`를 스마트폰으로 복사 → 시각 기록
4. 케이블을 뺀다 → 시각 기록

### S4. 아무 행동도 하지 않은 PC (오탐 확인)

S0에서 `tester1`로 로그인만 하고 10분 뒤 종료.
*확인하려는 것:* 보고서가 "확인 필요"를 내지 않아야 한다

### S5. 흔적 지우기

1. S1의 1~8을 수행
2. 휴지통 비우기 → 시각 기록
3. 이벤트 뷰어에서 "시스템" 로그와 "보안" 로그를 지운다 → 시각 기록
4. 브라우저 방문 기록 삭제 → 시각 기록

### S6. 시계 바꾸기

1. 날짜를 3일 전으로 바꾼다 → 실제 시각과 바꾼 시각을 모두 기록
2. USB A를 꽂고 파일 하나를 연다 → 화면의 시각과 실제 시각을 모두 기록
3. 날짜를 원래대로 돌린다 → 기록

### S7. 여러 계정

`tester1`이 USB A의 파일을 열고 로그아웃 → `tester2`가 로그인해 PC 파일 하나를 삭제. 각각 시각 기록.

### S8. 브라우저

Chrome, Edge, Whale, Firefox 각각에서:
1. `https://example.com` 방문 → 시각 기록
2. 파일 하나 내려받기 (예: 브라우저 설치 파일) → 시작 시각, 저장 경로 기록
3. 웹메일·클라우드 저장소 **로그인 화면까지만** 방문 (로그인하지 않는다) → 시각 기록

### S9. 네트워크·블루투스

1. 유선 연결 상태 기록 → Wi-Fi A에 연결 → 시각, 이름(SSID) 기록
2. Wi-Fi B(스마트폰 핫스팟)에 연결 → 시각, 이름 기록
3. 블루투스 이어폰이나 스마트폰을 페어링 → 시각, 장치 이름 기록

### S10. 실행 중 점검 (Phase 3 이후)

브라우저와 Word를 열어 둔 채로 점검 도구를 **USB A에서** 실행.
*확인하려는 것:* 잠긴 파일을 읽는가, 도구가 담긴 USB A가 "처음 보는 장치"로 잡히지 않는가.
점검 직전·직후 가상 머신 스냅샷을 찍어 두면 "점검이 PC에 남긴 변화"를 비교할 수 있다.

## 3. 자료 꺼내기

정상 종료한 가상 디스크를 **읽기 전용으로** 연결한 뒤(예: 다른 가상 머신에 두 번째 디스크로 "읽기 전용" 연결), 그 드라이브 경로를 `trace analyze --input`에 준다.

> 폴더를 탐색기로 복사해 오면 파일 시각이 바뀐다. 바로 가기의 "열람 시각"은 파일 시각에서 나오므로, **복사본이 아니라 읽기 전용으로 연결한 드라이브를 직접** 입력으로 써야 한다.

## 4. 기록표 양식

시나리오마다 한 장씩 쓴다.

```
시나리오: S1        Windows: 10 22H2 / 11 24H2      가상 머신 시간대: 대한민국 표준시
계정: tester1       USB B: 제조사 ______ 모델 ______ 용량 ____ 볼륨 일련 번호 ____-____

번호 | 시각(시:분:초) | 한 일                              | 비고(드라이브 문자, 경로 등)
-----+----------------+------------------------------------+------------------------------
  1  | 14:02:10       | USB B 연결                         | E:
  2  | 14:04:30       | E:\자료\usb문서_시험.docx 열기     |
  3  | ...            |                                    |
```

## 5. 주의

- 시험용 USB와 가상 머신은 이 용도로만 쓴다.
- 만든 가상 디스크에는 Windows 사용권 정보가 들어 있으므로 저장소에 올리지 않는다. 저장소에는 **뽑아낸 아티팩트 파일과 기록표만** 올린다.
